# Zelora Digital Systems WordPress Theme

Converted from the supplied `index.html` source.

## Install
Upload the ZIP in WordPress: Appearance -> Themes -> Add New -> Upload Theme. Activate it.

## Frontend editing
Appearance -> Customize -> Zelora Homepage. Edit hero, about, services, process, industries, contact, footer, images and URLs. Values are stored in WordPress theme modifications in the database.

## URLs
Each major section, CTA, KPI, service and process step has an editable URL.

## Menus
Primary Menu and Footer Menu are registered. If no menu is assigned, fallback navigation uses the Customizer section URLs.

## Fonts
The supplied local font files are used. The broken Google Fonts dependency is removed.

## Contact form
The contact form submits through WordPress AJAX and emails the WordPress Administration Email Address. SMTP is recommended for production.
